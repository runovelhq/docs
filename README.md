# Runovel Documentation

This repository is the future central documentation portal for Runovel.

Project-specific, versioned technical documentation remains in each project
repository. This portal will provide product discovery, shared architecture and
operations guidance, migration documentation, security and support entry
points, and cross-project navigation.

## Planned architecture

- Generator: MkDocs Material
- Initial hosting: GitHub Pages
- Future domain: `docs.runovel.com`
- Versioning: stable project documentation remains tied to project releases
- Source of truth: project details stay with project code; this portal links and
  curates rather than duplicating them

The full documentation site is intentionally deferred to a later action.
